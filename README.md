# 📌 Project Overview

This project deploys a Python Flask Calculator application into a Kubernetes cluster using a complete DevOps workflow.

The pipeline includes:

- GitHub Actions (CI)
- Docker
- Docker Hub
- Kubernetes (Minikube)
- Helm
- ArgoCD (GitOps)
- Prometheus
- Grafana
